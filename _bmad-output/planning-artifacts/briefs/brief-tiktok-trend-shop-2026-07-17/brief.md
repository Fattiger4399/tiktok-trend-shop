# Product Brief: 亚马逊热点商品选品与宣传物料生成平台

## Executive Summary

为跨境电商卖家（甲方）提供「选品 → 定制物料 → 在线审批」的一站式服务平台。运营侧从三方数据源汇聚亚马逊热点商品，并以商品为线索聚合全网图文详情，形成可信的商品档案；甲方在平台上按板块/分类浏览热点商品、选品并提交物料需求；平台基于商品档案用 AI 重新生成宣传文案与图片，甲方在线审批定稿后交付。

与通用 AI 物料工具的区别：物料不是从空白生成，而是从「已验证的热点商品 + 聚合的真实商品素材」出发——选品决策与物料生产在同一个闭环里完成。调研确认该形态暂无大牌直接对标（最接近的是 POD/一件代发的「目录+定制」模式），差异化在闭环，而非单点生成能力。

本项目由原「TikTok 趋势 → AI 视频」项目转向而来，已有 Go 后端、React 工作台、CSV 导入与类目体系等资产可直接复用（详见 addendum）。

## The Problem

跨境卖家追亚马逊热点时的现状：

- **数据割裂**：选品靠 Helium 10 / 卖家精灵等三方工具刷榜单，看中一个品之后，图片、文案、参数要自己去全网各处扒，拼凑成本高。
- **物料生产慢且贵**：做图写文案要么自己 PS，要么外包设计，来回改稿周期以周计；而热点窗口期短，物料做好时热度常常已过。
- **通用 AI 工具不对症**：现有 AI 物料工具（PhotoRoom、CopyMonkey 等）从空白生成，缺乏真实商品素材支撑，图文与实物脱节，且不管选品——用户仍要在多个工具间手工搬运。
- **需求表达成本高**：甲方往往说不清自己要什么，传统定制流程靠反复沟通磨合，误解多、改稿累、交付慢。

## The Solution

平台由两部分组成：

**甲方端（客户前台）**：选板块（亚马逊站点/市场，如美/欧/日）→ 选目标分类（母婴/床品/户外等）→ 浏览该分类热点商品（含趋势数据与档案完整度标识）→ 选品并提交物料需求 → 在线预览 AI 生成稿 → 审批通过或打回修改。需求输入按「甲方描述不清需求是常态」设计：结构化选项 + 场景模板 + AI 依据商品档案预填需求草稿，每次生成多个版本供甲方挑选微调——让甲方「做选择题」而不是「写作文」。

**运营交付后台**：数据源管理（MVP 为手工/CSV 导入三方榜单）、商品档案聚合与补全（全网图文素材采集 + 人工补录）、AI 生成任务管理与质量把关、订单与交付管理、甲方账号开通与管理。

核心链路：三方数据 → 热点商品库 → 全网图文聚合（商品档案）→ AI 生成（文案 + 图片）→ 甲方审批 → 交付导出。

## What Makes This Different

- **闭环**：选品数据与物料生产在同一平台，竞品（选品工具 / AI 物料工具）各自只做其中一段，用户在缝隙里手工搬运。
- **有据生成**：物料基于聚合的真实商品素材与事实性数据生成，而非模型凭空想象，图文与实物一致。
- **低表达门槛**：需求输入为结构化选项 + AI 预填 + 多版本供选，适配「甲方说不清需求」的现实，减少沟通往返。
- **诚实声明**：没有技术护城河——LLM 与图像生成能力是 commoditized 的。壁垒是热点响应速度、运营效率，以及与甲方工作流的贴合度。

## Who This Serves

- **甲方（主）**：跨境电商卖家/品牌方，需要在热点窗口期内快速拿到可用宣传物料。特点：不一定能清楚描述需求，需要被引导。
- **运营方（次）**：平台运营团队，负责数据维护、档案补全、生成质量把控与交付。

## Success Criteria

- 甲方从选品到拿到审批通过的物料包 ≤ 48 小时（对标外包 1–2 周）。
- 单批物料一次审批通过率 ≥ 60%，打回到定稿平均轮次 ≤ 2。
- MVP 验证期：跑通 ≥ 3 个真实甲方、≥ 20 个商品的完整闭环。

## Scope

**MVP 包含**

- 甲方端：板块/分类浏览、热点商品列表与详情、选品 + 需求提交（结构化 + AI 预填）、生成稿多版本预览与审批/打回。
- 运营后台：CSV 榜单导入、商品档案管理（含聚合素材）、生成任务队列管理、订单与按次计费记录（线下结算）、交付管理、甲方账号管理。
- AI 生成：宣传文案 + 图片（基于商品档案素材，可二次生成）。生图走本地 RTX 5080 + ComfyUI worker：平台部署在云服务器供甲方访问，worker 主动从服务器拉取生成任务、产图后回传（已确认，2026-07-17）。
- 审批流：在线审批/打回、版本记录、交付导出。
- 部署与账号：云服务器部署 + HTTPS；甲方账号鉴权为 MVP 必需（客户要访问，不再是无鉴权的本地评估形态）。

**MVP 明确不做**

- 视频物料（原 TikTok 视频管线搁置，代码保留不删）。
- 付费数据 API 直连（Keepa / 卖家精灵均有官方 API，二期评估）。
- 爬虫直连亚马逊或三方数据站（ToS 合规风险，二期再议）。
- 甲方自助注册、在线支付、多语言界面。

## Vision

2–3 年：成为跨境卖家的「热点响应中枢」——数据源 API 实时接入、图文视频全物料覆盖、审批通过的物料一键铺到 Amazon listing；审批偏好与上架表现数据回流，持续优化选品推荐与生成质量。

## 假设与开放问题

**已确认（2026-07-17）**

- 「板块」= 亚马逊站点/市场（美/欧/日等），板块内含商品分类。
- 生图方案：本地 RTX 5080 + ComfyUI worker，平台部署云服务器，产物回传服务器。
- 部署形态：客户经公网 URL 访问网站，甲方登录鉴权 + HTTPS 为 MVP 必需。
- 数据初始化：清理蝉妈妈/TikTok 旧演示数据，替换为真实亚马逊榜单数据。
- 数据源：MVP 为手工/CSV 导入三方榜单，二期评估 API 直连。
- 详情聚合：MVP 为半自动（搜索/抓取 + 人工补录）；聚合图仅作生成参考，交付图一律 AI 重生成。
- 甲方账号：运营后台开通，不做自助注册；多甲方数据隔离。
- 商业模式：按次收费（线下结算，MVP 不做在线支付）。
- 文案 LLM：走三方 API（DeepSeek/通义等），5080 显卡专留生图。
- 设计约束：甲方描述不清需求是常态——需求输入结构化/模板化/AI 预填，多版本供选。

**仍待确认**

- 开放：甲方量级与并发需求未知（影响单 worker 生图排队与扩容计划）。
